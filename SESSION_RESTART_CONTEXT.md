## Frequency-response update (2026-03-26)

- The nominal frequency workflow was extended to a `1e-3` to `1e1 rad/s`,
  `80`-bin grid for the `run4` campaign.
- Remote execution was moved to `helpers/omc_gw` with reduced CSV output at
  simulation time via OpenModelica `-variableFilter`.
- Future remote scheduling convention:
  - prefer `1` sweep job per worker
  - reserve `16` remote task slots with `--tasks 16`
  - run the sweep itself with `--n_jobs 16`
  - do not pack multiple sweep jobs onto one worker unless there is a specific
    reason to accept higher I/O pressure
  - the March 26, 2026 `8`-task tail reruns were only a conservative repair
    step, not the preferred default
- A low-frequency plotting problem at `0.01 MW` was diagnosed as a
  large-signal forcing artifact, not just lack of cycles:
  - old `--sin_mag_auto` gave `10 pcm` at `0.01 MW`
  - the slow band (`<= 1e-2 rad/s`) became nonstationary over long runs
  - longer `stop_time` and longer `ss_time` alone did not fix it
  - rerunning the slow band at `1 pcm` did fix it
- The durable code fix is in `freq/runFreqNominalParallel.py`:
  - when `--sin_mag_auto` is enabled and `power <= 1e-2`,
    `sin_mag` is now capped at `1 pcm` for `omega <= 1e-2 rad/s`
  - above `1e-2 rad/s`, the usual auto-scaled amplitude is kept
- Accepted `0.01 MW` plots were regenerated from a merged summary-only tree:
  - `freq/results_0p01_default_autoforcing`
  - this uses the `1 pcm` slow-band rerun plus the original `run4` higher bins
  - plot outputs updated:
    - `freq/BodePlots_run4/BodePlot_1r_power_0p01.png`
    - `freq/BodePlots_run4/BodePlot_9r_power_0p01.png`
    - `freq/BodePlots_run4_compare/BodePlot_compare_1r_9r_power_0p01.png`
- Follow-up low-power investigations were completed for `0.001 MW`, `1e-4 MW`,
  and `1e-5 MW` using `omc_gw`:
  - long settle alone collapses the nonphysical `1r`/`9r` gain split
  - long settle + `1 pcm` restores good fit quality
  - accepted summary tree:
    - `freq/results_lowpower_default_protocol`
  - updated plots:
    - `freq/BodePlots_run4/BodePlot_1r_power_0p001.png`
    - `freq/BodePlots_run4/BodePlot_1r_power_0p0001.png`
    - `freq/BodePlots_run4/BodePlot_1r_power_0p00001.png`
    - matching `9r` and compare plots
- `freq/runFreqNominalParallel.py` now defaults to the full low-power protocol
  for `power <= 1e-2`:
  - `ss_time >= 400/power`
  - `stop_time >= ss_time + min(5e4, ss_time/4)`
  - dynamic `12` post-forcing cycles
  - frequency-scaled output grid (`6` samples/period target, `50 s` max step)
  - slow-bin `1 pcm` cap remains under `--sin_mag_auto`
- Detailed diagnosis and artifact paths are documented in
  `freq/INVESTIGATION_CONTEXT.md`.
